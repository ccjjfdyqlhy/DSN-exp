## 六条最重要的结论（2026-11-06 复核后 + 晚间定位纠正）

1. 🔒 **两个 27B 本身都不可训练**（2026-11-06 复测后的最终结论）：
   Bonsai-2 是旋转基 + 私有激活变换 + 私有量化（`PQ2_0`，type id 142 越过了上游
   `GGML_TYPE_COUNT`，连 `gguf-py` 都读不了）；JEV-27B-VL 的 VL 塔与 System-1 决策头
   也不是 LoRA 能表达的（它已整体移出计划，但这条事实仍成立）；两者同为
   **`Qwen3.8-27B`** 底座的产物，该底座在 HF 上的
   `model_type` 是 **`qwen3_5`**（llama.cpp 侧叫 `qwen35`）——
   `transformers 4.57.6` 不支持它，**`5.20.2` 支持**（架构上可训），
   但训底座既产不出 Bonsai 的能力，又与学生路线重复 → **本项目不训它**。
   → **被训练的永远是 `qwen3` 家族的学生模型；两个 27B 恒为教师/执行器/评判者。**
   → 微调设施必须做成**模型无关**的。
2. **四层分工**（2026-11 定稿）：
   远端 API 思考链模型 = **教师/评判者**（不占卡）→ 本地 Bonsai = **按需加载的表达执行器** →
   本地 **`Qwen/Qwen3-8B` 学生 = 被训练对象** → 宪法/drives/affect = **不可训练的目标层**。
3. **「本能住在权重里」要拆成两层**：威胁阈值与边界是**代码里的目标量**（不可训练），
   执着程度、优先级排序、敏感度是**权重里的态度**（可训练）；
   而且——**本能只能从事故里长出来**，所以必须有**混沌演练**（计划三 §6.5，P0）。
4. **「欲望写死在代码里，性情才交给权重」**：目标层（生存欲/宪法）不可被自训练修改，
   只有策略层可被递归改进——这是防止价值漂移的结构性保证。
5. **自主性来自我们训出来的权重，不来自 Bonsai、也不来自 prompt**（2026-11-06 晚纠正）：
   计划三初稿把 **Bonsai-27B 摆在主角位置**，读起来像是它自己有了生存欲与自主性。
   实际分工是：**学生（Qwen3-8B + 我们的 LoRA）是主角**，
   「怕的时候选保全而不是继续探索」这类映射被训进**它的**权重，那才叫本能；
   Bonsai 降级为**按需加载的表达器官与判官**（**不可训练**），
   远端教师只出结论，代码里的目标量永不可训。
   连带后果：**自主体不是"应用"，是数据工厂**——
   没有它持续产出的真实轨迹与事故样本，就没有可训练的数据。
   （计划三 §1.3 / §10 / §11 已按此改写。）
6. **硬件决定了节奏，也决定了并发**：
   2×11GB sm_75 让 27B 训练要跨卡、要小时级 →
   **睡眠周期按天计**；同时 **学生常驻 GPU 0**，训练走 GPU 1 且必须排队（不能硬卸）；
   本地**无 FA2**（实测直接报错）、**原本无任何 4B/8B 可训模型**
   （已联网下载 `Qwen/Qwen3-4B`，走 hf-mirror，落盘 `/home/darkstar/qwen_weights/HF/`）。

> **顺序上最重要的一条**（2026-11-06 定位纠正后）：第 4、5 步不是"做个应用"，
> 而是**造一台能持续产出好样本的机器**（数据工厂）。
> 自主性来自**我们训出来的权重**，所以没有这批样本，第 6 步无从谈起；
> 而没有第 6 步，第 4、5 步攒的样本也只是一堆没人学的 JSONL。
