The first release candidate. It ships the three things the runtime needs to be
trustworthy in production: a tool call is admitted or refused, a crashed run
resumes without repeating its side effects, and every change is scored.

## What it delivers

- **A tool guard.** Every tool call goes through a policy gate, an approval
  step, a sandbox and an audit trail. The guard is attached by default, so the
  SDK and the CLI path are guarded, not just the fixtures.
- **A managed runtime.** Sessions, turns, events, a journal, checkpoints and
  idempotency keys. A run that is killed once resumes and reports which side
  effects may already have happened. An effectful call is never replayed on
  its own.
- **An evaluation loop.** A 40-case dataset ships with the package, together
  with an evaluator, a trace store, run versions and a four-gate report
  (quality, regression, cost, safety). The safety gate has no off switch.

## The three claims

| claim | how it is verified |
|---|---|
| an agent that is `kill -9`'d once still resumes and produces the right answer | `tests/fault/` kills a real child process |
| every tool call was either approved or refused, with an audit trail | `tests/test_rc0_guard.py`, `tests/test_rc0_approval.py` |
| the run is scored by a >=30 case dataset and produces a four-gate report | `tests/test_rc0_eval.py` and the `aicf eval` / `aicf gate` commands |

## Try it

```bash
pip install "aicf-core==1.0.0rc0"
aicf tool list
aicf run "summarize this repository" --trace trace.jsonl
aicf eval --dataset basic --traces trace.jsonl --out run.json
aicf gate --run run.json --out gate.json
```

Every step runs offline against a stub model.

## What is still missing

This release candidate covers the runtime, not the control plane. Missing on
purpose, and named in
[the roadmap](../roadmap_1.0.0-rc0.md): the agent artifact model and its
lifecycle, the workflow and planner kernels, agent identity with delegation,
online sampling with bad case feedback, and failover across machines.

The immutable audit store is also not wired to the guard yet: the audit events
reach the trace, but not the undeletable store.
