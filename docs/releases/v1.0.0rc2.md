# v1.0.0rc2

> ⚠️ **命名空间说明**：本文记录的是 1.0.0rcX 当时的 API 形态。
> 自 **1.0.0** 起，import 路径改为 `aicf.harness.*` / `aicf.infra.*`
> （顶层不再占用 `harness` / `infra` 两个名字）。迁移对照见
> [CHANGELOG.md](../../CHANGELOG.md) 与 README 的「迁移」小节。

The second release candidate. It does not add a new capability to the
runtime; it fixes where the state of an application lives and gives the
sandbox a write level it can actually enforce.

## What it delivers

- **A document store.** `infra/store/documents.py` holds a generic
  interface for one json document, read whole and written whole, with the
  bytes in the application's own database. The todo plan
  (`TodoStore(backend=...)`), the duration predictor
  (`DurationPredictor.load/save(backend=...)`) and the lightweight todo
  tool use it.
- **A state directory outside the project.** The engine's default moved
  from `<cwd>/sessions/agent.db` to a user level directory: `$AICF_HOME`,
  or `~/.aicf`. An application that wants another place passes its own
  path. The old files are read once and taken over.
- **A sandbox write level that holds.** `ToolSpec.sandbox='readonly'`
  now means the working directory is not a writable root, through the new
  `PathPolicy.cwd_writable` and `SandboxRequest.cwd_writable`. Before
  this, the "the working directory is writable too" rule turned a
  read-only project back into a writable one.
- **A fix for the cancelled turn.** `pop_context` restores the tool
  context only in the context that pushed it, and logs the case where it
  cannot. A turn cancelled while a tool call was in flight no longer
  fails over the cleanup.

## Try it

```bash
pip install "aicf-core==1.0.0rc2"
python -c "import harness; print(harness.__version__)"
```

## What is still missing

The same list as rc0, and it has not shrunk: the agent artifact model
and its lifecycle, the workflow and planner kernels, agent identity with
delegation, online sampling with bad case feedback and failover across
machines. The immutable audit store is still not wired to the guard. The
plan and the status of each workstream live in
[the roadmap](../roadmap_1.0.0-rc0.md).
