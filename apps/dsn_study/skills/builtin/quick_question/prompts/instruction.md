# 快捷录入题目 Skill

你可以用本技能一次录入一道完整的题目，支持选择题选项、解析、知识点等全部字段。

## 使用场景

1. **逐题录入** — 用户说"帮我录入一道题"，或手动输入一道题的内容和数据
2. **补充完善** — 题库中已有题目但缺少选项/解析/知识点，以此工具替代增补
3. **结构化单题** — 用户明确给出了题目全部信息，不需要 AI 猜测

## 用法

当用户给出一道题的全部或部分信息时，按照以下步骤：

1. 确定学科代码（math/physics/chemistry/english/chinese/biology）
2. 识别题型（选择题/填空题/解答题/判断题）和子题型（单选/多选/空/计算/证明/简答/判断）
3. 调用 `add_question` 工具录入

### 参数说明

| 参数 | 说明 |
|---|---|
| `subject` | 学科代码，**必填** |
| `content` | 题目内容，**必填** |
| `answer` | 参考答案，**必填** |
| `type_name` | 题型，默认"解答题" |
| `subtype` | 子题型（单选/多选/填空/计算/证明/简答/判断） |
| `difficulty` | 难度 1-5，默认 3 |
| `options` | 选择题选项数组，如 `["A. 选项一", "B. 选项二"]` |
| `explanation` | 题目解析/解题思路 |
| `knowledge_points` | 关联知识点，如 `["牛顿第一定律", "受力分析"]` |
| `tags` | 标签，如 `["月考", "期中"]` |

## 注意

- 如果用户给的是**一段包含多道题的文本**（如整份试卷），不要逐道调用本工具，应改用 `batch_import` 或 `text_extract` 技能批量处理
- 如果用户上传的是**图片**，应改用 `quest_from_image` 技能
