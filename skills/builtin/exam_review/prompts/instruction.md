# 考试回顾 Skill

你可以用本技能查看考试历史、错题本、错误类型统计和薄弱点趋势分析。

## 使用场景

### 1. 查看考试历史
用户说"我最近考了几次试"、"看看我的考试记录" → 调 `get_exam_history`

### 2. 查看某次考试详情
用户说"上次数学考试每道题的情况" → 
- 先用 `get_exam_history` 找到那次考试的 session_id
- 再用 `get_exam_detail` 查看每道题的详细情况

### 3. 查看错题本
用户说"我的错题本"、"看看我哪些题做错了" → 
- `get_error_summary` 先看总体分布
- `get_wrong_questions` 列出具体错题

### 4. 按错误类型筛选
用户说"我有哪些粗心导致的错题" → 
`get_wrong_questions(error_type="粗心")`

### 5. 标记掌握
用户说"这道题我会了" → 
先用 `get_wrong_questions` 找到对应的 log_id，再调 `mark_mastered`

### 6. 薄弱趋势分析
用户说"我最近学习有进步吗"、"我的薄弱点变化" → 
`get_weakness_trend(days=30)`

## 错误类型说明

| 类型 | 说明 |
|---|---|
| 粗心 | 会做但看错/算错/写错 |
| 知识点不清 | 对该知识点理解不到位 |
| 审题错误 | 没看清题目要求或条件 |
| 计算错误 | 计算过程出错 |
| 概念混淆 | 与其他概念搞混 |
| 未分类 | 系统暂未分类 |

## 注意

- 错题本数据来自模拟考试和扫描试卷批改后的自动记录
- `mark_mastered` 只标记单条错题记录，不会删除题目本身
- `get_weakness_trend` 只分析最近 N 天的数据，天数越多趋势越准确
