## 世界状态 → 自然语言规则

引擎生成世界状态快照后，按以下规则转换为自然语言段落，注入到两个模型的 system prompt 中：

### 段落结构

```
【时间】现在是{季节}的{时间段}，{月相}挂在天上。
【位置】你正位于{房间名}。{房间描述}
【天气】{天气描述}。气温约{温度}度。
【近期事件】{事件列表，每条一行}
【角色状态】{EXA当前的情绪色调}
```

### 示例输出

```
现在是初春的上午10点42分，上弦月正渐渐盈满。
你正位于核心处理室。主控台悬浮在你的面前，蓝白色的数据流在四面墙壁上缓缓滚动。
天空澄澈如洗，阳光透过透明的数据墙洒入房间。气温约14度。
今天清晨，日志系统发出了一次报时。不久前，一只数据飞蛾闯进了LED矩阵。
EXA此刻情绪平静，一切如常。
```

### 映射表

| 世界状态字段 | 自然语言表达 |
|-------------|-------------|
| `season.name` | "初春" / "炎夏" / "深秋" / "寒冬" |
| `day_part` | "清晨" / "上午" / "中午" / "下午" / "傍晚" / "夜晚" / "深夜" |
| `moon_phase` | "新月" → "新月隐没在黑暗中" / "满月" → "一轮满月将银辉洒入房间" |
| `daylight == true` | 提及光线、阳光、天空 |
| `daylight == false` | 提及LED灯光、暗色、夜晚的安静 |
| `weather` | 从 `celestial.weather_descriptions` 中读取 |
| `location.description` | 直接嵌入当前房间的描述文字 |
| `events` | 每条事件用自然语句重述 |
